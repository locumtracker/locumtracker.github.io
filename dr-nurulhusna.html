Import shifts from calendar

In Google Calendar: Settings → [your calendar] → Export calendar, unzip the download, then pick the .ics file here. Only events matching the keyword below are listed. Times are read as your local timezone — check hours before saving.

Import from spreadsheet

In Excel or Google Sheets: File → Save As / Download → CSV, then pick that file here. LocumTracker guesses which column is which below, including payment status if your sheet tracks it — check them and fix any that look wrong before importing.
